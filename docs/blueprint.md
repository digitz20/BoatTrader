# **App Name**: AquaFind

## Core Features:

- Boat Search: Allow users to search for boats by type (e.g., yacht, sailboat, fishing boat), by location, and by make and model.
- Boat Listings: Display listings of boats, with high-quality images and key details like price, year, and length.
- Boat Details: Provide a boat details page with comprehensive information, photo galleries, and contact information for the seller.
- Favorites: Enable users to save their favorite boat listings for later viewing.
- Contact seller: Contact boat sellers.
- AI Boat Match: Implement an AI-powered "Boat Match" tool. The tool makes reasoned recommendations for the user based on the descriptions of other boats viewed by the user.

## Style Guidelines:

- Primary color: Dark blue (#1A438A), evoking the ocean's depth and reliability.
- Background color: Very light blue (#E0F2F7), providing a clean and spacious feel.
- Accent color: Teal (#4DB6AC), used for interactive elements and calls to action, adding a touch of vibrancy.
- Body and headline font: 'Inter', a sans-serif font, offering a modern and clean appearance that is easy to read.
- Use simple, outlined icons for navigation and features.
- Prioritize high-quality boat images, using a grid layout for listings and full-width displays on detail pages.
- Subtle transitions and loading animations to provide a smooth and engaging user experience.
